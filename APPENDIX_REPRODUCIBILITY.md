# Appendix reproduction

Run from the repository root:

```text
Rscript reproduce_appendices.R
```

The wrapper reproduces Appendix A and Appendix E. It creates the generated
Scenario B data directory, renders the representative Scenario B analysis,
runs 20-fold cross-validation, and renders the replication-sensitivity study.

To control the Scenario B replication seeds, set
`SCENARIO_B_REPLICATION_SEEDS` to a comma-separated list. The default is
`1001:1100`.

The main appendix sensitivity and cross-validation outputs are regenerated by:

```text
Rscript reproduce_examples.R
```

The historical Appendix B R Markdown file contains non-portable legacy paths;
its portable data and shared functions are retained in the repository, but
the legacy file requires path replacement before direct rendering.
